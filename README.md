# ФСВНГ — база знаний

Материалы фракции Росгвардия (GTA 5 RP, сервер Тверской): уставы, лекции, система повышения и сайт для курсантов.

**Кто:** Сержант **Максим Королев**, ранг 4. Должность — **инструктор**: проводит лекции и принимает присягу.

## Шпаргалка

**Коды обстановки:** Код-1 спокойно · Код-2 подозрительные лица · Код-3 проникновение или нападение · **Код-4 боевая тревога**

**Распорядок:** служебный день 11:00–21:30 · обед 18:00–19:00 · вечерняя проверка 21:00 · присяга 12:00 и 20:00

**Дисциплина:** устный выговор = 1 активный, строгий = 2, **три = увольнение**. Отработать за 48 часов. Нарушения сотрудников ФСВНГ ведёт **ОСБ**.

**Три вещи, на которых валятся чаще всего:**
1. **Бодикамера** — включена везде, кроме построения на плацу, плашка с красным индикатором в кадре
2. **`/f`, а не `/fb`** — доклады только в IC-чат
3. **Скриншот целиком** — обрезка или редактирование расценивается как попытка ввести руководство в заблуждение
