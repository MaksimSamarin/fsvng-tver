## Зафиксированные расхождения

1. **Ст. 23 ДУ — расхождение снято.** В редакции от 10.09.2026 ст. 23 называется «Самоуправство и неуставные взаимоотношения», что совпадает с формулировкой лекции по субординации. В прежней редакции ст. 23 была про форму одежды вне службы.
2. **Посты на Алабино.** Лекция перечисляет 6 постов, устав (ст. 22.1) закрепляет 3 постоянных. Разбор — [в конспекте УКПС](устав-караульно-постовой-службы.md#расхождение-с-лекцией-по-постовой-службе).
3. **КПП №2.** На полигоне «Алабино» — основной пункт прохода (ст. 22.1). В воинской части — резервно-служебный, работает только при закрытии КПП №1 (ст. 31). Разные объекты, не путать.
