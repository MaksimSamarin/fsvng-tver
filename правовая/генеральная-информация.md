# Генеральная информация о ВС и ФСВНГ

**Источник:** форум «Россия Онлайн», Министерство обороны. Автор — Владимир Воронин (Лидер государственной организации), 02.09.2026.

---

## Структура

**Федеральная служба войск национальной гвардии Российской Федерации (Росгвардия)** — федеральный орган исполнительной власти, созданный для обеспечения государственной и общественной безопасности, защиты прав и свобод граждан.

**Вооружённые Силы Российской Федерации (ВС РФ)** — государственная военная организация, составляющая основу обороны страны. Предназначены для отражения агрессии, направленной против РФ, вооружённой защиты целостности и неприкосновенности её территории, а также для выполнения задач в соответствии с федеральными конституционными законами, федеральными законами и международными договорами РФ.

**Специальная связь** — отдельный Discord («Спецсвязь»). Присоединение по памятке «Получение ролей в спец. связи» — требование для повышения 1→2.

---

## Внутренняя иерархия (по ст. 4.1 Устава ВС)

Генерал Армии → Генерал-Полковник Армии → Начальник ВС и его заместители → Начальник ФСВНГ и его заместители → командиры подразделений.

При исполнении обязанностей **должность имеет приоритет над званием** (ст. 4.2): занимающий вышестоящую должность — старший по должности независимо от звания, в пределах своих полномочий.

## Подразделения (ст. 4.4)

| Тег | Подразделение |
|-----|---------------|
| ВП | Военная полиция — правопорядок и дисциплина |
| МР | Медицинская рота |
| ГРУ | Главное разведывательное управление |
| ССО | Силы специальных операций |
| МСК | Мотострелковый корпус |
| ВК | Военный комиссариат |
| ОСБ | Отдел собственной безопасности |
| РВО | Рота вневедомственной охраны |
| ОМОН | ОМОН |
| КС | Кадровая служба |

Плюс Военная академия — отвечает за выдачу военных билетов.

**После 3 ранга** курсант ФСВНГ автоматически зачисляется в РВО. Из РВО можно подать заявку на перевод в ОМОН, ОСБ, Кадровую службу или АВНГ — по одобрению подразделения; дальше рост идёт по системе повышения своей структуры.

**Кадровая служба и АВНГ — два разных подразделения ФСВНГ:** АВНГ (Академия ВНГ) занимается обучением курсантов, КС — кадровая работа по всему ФСВНГ.
