# Чек-лист: ранг 2 → 3

## Требования

| ✔ | Пункт | Что нужно | Доказательство |
|---|-------|-----------|----------------|
| [ ] | 1. Стрельбище | **2 скриншота**: начало тренировки и завершение | |
| [ ] | 2. Физподготовка | **2 скриншота**: начало и конец тренировки | |
| [ ] | 3. Полоса препятствий | **2 скриншота**: начало и конец прохождения | |
| [ ] | 4. Караул КПП 1/2, Алабино — 1 час | 5 скриншотов + доклады в `/f`, см. [журнал караула](../шаблоны/доклады-караул.md) | |
| [ ] | 5. Экзамен по внутренним НПА | **1 скриншот результата**, один экзамен сразу по всем семи документам | |

Присяга и строевая подготовка принимаются на этапе **1 → 2** — см. [чек-лист 1 → 2](ранг-1-2.md).

⚠️ Выезд с территории ВЧ — **только с сотрудниками** `@[🎓] Академия Войск Национальной Гвардии`. Самостоятельный выезд запрещён.

## Подготовка к караулу

- [ ] Полная экипировка: бронежилет, оружие, патроны, сухпайки
- [ ] Бодикамера включена (плашка с красным индикатором)
- [ ] Шаблоны докладов подготовлены — [доклады-караул.md](../шаблоны/доклады-караул.md)
- [ ] Доклады пишутся в **`/f`**, а не в `/fb`
- [ ] Знаю расстановку своего поста ([схема постов](../docs/лекция-постовая-служба.md#2-расстановка-постов-полигон-алабино))

## После 3 ранга

Переход в **РВО** — автоматически. **С 5 ранга** можно перевестись в **ОМОН**, **ОСБ** или **Кадровую службу ФСВНГ** либо остаться в РВО, перевод только по одобрению. Дальше — система повышения своей структуры.
