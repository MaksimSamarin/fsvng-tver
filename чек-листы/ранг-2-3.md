# Чек-лист: ранг 2 → 3

## Требования

| ✔ | Пункт | Что нужно | Доказательство |
|---|-------|-----------|----------------|
| [ ] | 1. Присяга | Отыграть по [процедуре](../docs/присяга.md), текст — в [отписках](../шаблоны/отписки.md#3-присяга). Ежедневно 12:00 и 20:00 на плацу | |
| [ ] | 2. Стрельбище | **2 скриншота**: начало тренировки и завершение | |
| [ ] | 3. Тренировочная площадка | **2 скриншота**: начало полосы препятствий и конец | |
| [ ] | 4. Караул КПП 1/2, Алабино — 1 час | 5 скриншотов + доклады в `/f`, см. [журнал караула](../шаблоны/доклады-караул.md) | |

⚠️ Выезд с территории ВЧ — **только с сотрудниками** `@[👮] Кадровая служба ФСВНГ`. Самостоятельный выезд запрещён.

## Подготовка к караулу

- [ ] Полная экипировка: бронежилет, оружие, патроны, сухпайки
- [ ] Бодикамера включена (плашка с красным индикатором)
- [ ] Шаблоны докладов подготовлены — [доклады-караул.md](../шаблоны/доклады-караул.md)
- [ ] Доклады пишутся в **`/f`**, а не в `/fb`
- [ ] Знаю расстановку своего поста ([схема постов](../docs/лекция-постовая-служба.md#2-расстановка-постов-полигон-алабино))
