# Готовые отписки — Сержант Максим Королев

Всё подставлено, копировать как есть. Менять только **время**.
Текущий пост: **КПП№2 Алабино** (двое слева и справа от шлагбаума, один за шлагбаумом).

> ⚠️ `/f` — IC-рация (сюда доклады). `/fb` — OOC, туда служебное **не пишем**.
> Вне ВЧ — бодикамера включена, плашка с красным индикатором в кадре.

## 1. Караул: доклады в `/f`

### Заступление на пост
```

```

### Промежуточные (каждые 15 минут)
```

```
```

```
```
/f Докладывает Сержант Росгвардии Максим Королев - время 16:45 - КПП№2 Алабино - состояние стабильное - доклад окончил.
```

### Сдача поста
```
/f Докладывает Сержант Росгвардии Максим Королев - время 17:00 - КПП№2 Алабино - пост сдал - состояние стабильное - доклад окончил.
```

### Если пост другой — подставить вместо `КПП№2 Алабино`
`КПП№1 Алабино` · `Наблюдательная вышка Алабино` · `Вышка "Оружейки"` · `Вышка "Огневой рубеж"` · `Вышка "Лагерь"`

### Шаг по времени
Заступил не в ровный час — шаг тот же. Старт 17:20 → доклады и скриншоты в **17:20, 17:35, 17:50, 18:05, 18:20**.

## 2. Караул: нештатные ситуации

### Обнаружено проникновение
```
/f Докладывает Сержант Росгвардии Максим Королев - время ЧЧ:ММ - КПП№2 Алабино - обнаружено проникновение на территорию - прошу группу реагирования - доклад окончил.
```

### Прибытие сотрудников госструктур
```
/f Докладывает Сержант Росгвардии Максим Королев - время ЧЧ:ММ - КПП№2 Алабино - на пост прибыл сотрудник [структура], цель прибытия - [цель], документы проверены - ожидаю указаний - доклад окончил.
```
Порядок: узнать цель прибытия → запросить служебное удостоверение → доложить по рации → ждать указаний.

### Доклад на вечерней проверке с поста (21:00, ст. 2.4)
```
/f Докладывает Сержант Росгвардии Максим Королев - время 21:00 - КПП№2 Алабино - нахожусь на посту, пост не покидаю - состояние стабильное - доклад окончил.
```

### Запрос на оставление поста
```
/f Докладывает Сержант Росгвардии Максим Королев - время ЧЧ:ММ - КПП№2 Алабино - прошу разрешения оставить пост, причина - [причина] - доклад окончил.
```

> Покидать пост без доклада и разрешения — **ст. 9 ДУ** (увольнение при оставлении поста). До прибытия смены пост не оставляется (**ст. 7.4** Устава).

## 3. Присяга

Порядок отыгровки: инструктор передаёт папку → ты берёшь → произносишь текст → инструктор подтверждает.

### Твоя отыгровка
```
/me взял в руки папку с текстом
```

### Текст присяги (произносится в чат)
```
Я, Королев Максим, торжественно присягаю на верность своему Отечеству — Российской Федерации. Клянусь свято соблюдать Конституцию Российской Федерации, строго выполнять требования воинских уставов, приказы командиров и начальников. Клянусь достойно исполнять воинский долг, мужественно защищать свободу, независимость и конституционный строй России, народ и Отечество.
```

Присяга проводится ежедневно **в 12:00 и 20:00 на плацу** (и в любое время по договорённости). О построении объявляют в новости.

## 5. Тренировки (на отчёт 2→3)

### Стрельбище — начало
```
/me занял позицию на огневом рубеже, проверил оружие и снаряжение
```
### Стрельбище — завершение
```
/me разрядил оружие, поставил на предохранитель, покинул огневой рубеж
```

### Полоса препятствий — начало
```
/me занял исходное положение перед полосой препятствий
```
### Полоса препятствий — завершение
```
/me преодолел полосу препятствий и вернулся в исходное положение
```

> На каждое — **по два скриншота** (начало и конец), это прямое требование системы повышения.

## 6. Выезд за пределы ВЧ и патруль

С младшего сержанта (**ст. 2.6**): увольнительное время **60 минут в день** (можно двумя по 30) и выход после службы — при отсутствии ограничений, наряда, тревоги или дисциплинарного запрета. Сопровождение Кадровой службы больше не требуется — это было правило для курсантов 1–2 ранга.

### Запрос на выезд в составе патруля
```
/f Докладывает Сержант Росгвардии Максим Королев - время ЧЧ:ММ - прошу разрешения на выезд в составе патруля, цель - [агитационно-мобилизационная работа / сопровождение / патрулирование объекта] - доклад окончил.
```

### Заступление на патруль по полигону
```
/f Докладывает Сержант Росгвардии Максим Королев - время ЧЧ:ММ - заступил на патрулирование полигона Алабино - состояние стабильное - доклад окончил.
```
Самостоятельное заступление допускается, отдельное назначение не обязательно (**ст. 22.2 УКПС**).

### Заступление на блокпост / ППС на дороге
```
/f Докладывает Сержант Росгвардии Максим Королев - время ЧЧ:ММ - заступил на блокпост [место] - состояние стабильное - доклад окончил.
```
Организация патрульно-постовой службы и **блокпостов на дорогах из городской части в областную** — основная задача ВС в мирное время (**ФЗ-2, ст. 6.1 п. 5**).

### Границы полномочий
- **Можно:** ППС и блокпосты на подведомственной территории и на дорогах город↔область (ФЗ-2 ст. 6.1 п. 5) · полигон «Алабино» (ст. 22.2 УКПС) · военкомат и пункты отбора (ст. 15 и 23 УКПС) · агитационно-мобилизационная работа (ст. 1.8 Устава ВС).
- **Нельзя:** патрулировать населённые пункты и общественные места как форму охраны общественного порядка — это полномочие полиции (ФЗ-6, гл. 3 п. 6). Патрулирование городских и сельских местностей **с тяжёлой и бронированной техникой** — только при ЧП или военном положении (ФЗ-2, ст. 12 п. 10).
- За внешней стороной КПП территория **не является режимным объектом** (ст. 37 УКПС): действуешь в пределах общего закона и вызываешь компетентные органы.
- Самостоятельно назначать наказание гражданским нельзя (ст. 5.3 Устава ВС).

Перед выходом в гражданской форме — сдать оружие, боеприпасы и спецсредства на склад (**ст. 3.4.2**).

## Чек перед любой отпиской

- [ ] Чат `/f`, а не `/fb`
- [ ] Бодикамера включена, плашка в кадре (вне ВЧ)
- [ ] Звание и ФИО написаны точно: `Сержант Росгвардии Максим Королев`
