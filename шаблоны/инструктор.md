# Отыгровки инструктора

Для проведения занятий с курсантами. `/do` — констатация факта и обстановки, попадает в кадр как подтверждение для отчёта курсанта.

> На каждое занятие курсанту нужно **по два скриншота** — начало и конец. Твои `/do` должны быть видны на обоих.

---

## Лекция-экскурсия по ВЧ

Требование для повышения **1 → 2**.

**Начало**
```
/do Лекция-экскурсия по территории воинской части начата.
```
**Конец**
```
/do Лекция-экскурсия по территории воинской части завершена, личный состав ознакомлен с расположением объектов и порядком передвижения.
```

---

## Стрельбище

Требование для повышения **2 → 3**.

**Начало**
```
/do Практическое занятие по огневой подготовке на стрельбище начато, проведён инструктаж по мерам безопасности.
```
**Конец**
```
/do Практическое занятие по огневой подготовке завершено, оружие разряжено, поставлено на предохранитель и сдано.
```

## Физическая подготовка

**Начало**
```
/do Занятие по физической подготовке начато, проведён инструктаж по мерам безопасности.
```
**Конец**
```
/do Занятие по физической подготовке завершено, нормативы отработаны.
```

Развёрнутый вариант:
```
/do Занятие по физической подготовке начато, личный состав построен, проведена разминка.
```
```
/do Занятие по физической подготовке завершено, личный состав нормативы сдал, замечаний нет.
```

## Присяга

**Передача текста курсанту**
```
/me аккуратно достал папку с текстом присяги и передал в руки новобранцу
```
**Подтверждение принятия**
```
/do Присяга успешно принята новобранцем.
```

Порядок и текст — [docs/присяга.md](../docs/присяга.md). Инструктор надевает китель и собирает построение на плацу; вызывается по одному человеку из строя. Ежедневно в 12:00 и 20:00.

## Лекция по правилам одежды

Требование **1 → 2**: дресс-коды, опознавательные знаки, погоны.

**Начало**
```
/do Лекция по правилам ношения формы одежды начата.
```
**Конец**
```
/do Лекция по правилам ношения формы одежды завершена, личный состав ознакомлен с дресс-кодом, опознавательными знаками и погонами.
```

---

## Что проверять у курсантов перед приёмом занятия

- [ ] Бодикамера с красным индикатором на скриншотах вне ВЧ
- [ ] Имя и фамилия в полной форме — не «Лёха», а «Алексей»
- [ ] Скриншот полного экрана, без обрезки и редактирования
- [ ] Доклады в `/f`, а не в `/fb`
- [ ] Выезд за территорию ВЧ — только в сопровождении Кадровой службы
- [ ] Отчёт строго по установленной форме, порядок пунктов не изменён

Полный список причин отклонения — [docs/частые-ошибки.md](../docs/частые-ошибки.md).
