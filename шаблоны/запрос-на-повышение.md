# Запрос на повышение

Подаётся в канал запроса https://discord.com/channels/1538938584441163776/1550924836400922635 **после** того, как на отчёте в `#🛡️отчет-на-повышение-курсанты` проставлена ✅.

Редакция формы — 19.09.2026 (пост Зам.КС в канале).

## Форма (порядок пунктов менять нельзя)

```
1. Тег себя (через @)
2. Текущий ранг - ранг на который повышаетесь
3. Ссылка на ОДОБРЕННЫЙ ОТЧЁТ
4. @Тег Кадровой службы
```

## Эталонный пример из канала

```
1. @Зам.КС | Денис Спасский | 65597
2. с 1 по 2
3. [ссылка на одобренный отчёт в #отчет-на-повышение-курсанты]
4. @[👮] Кадровая служба ФСВНГ
```

## Моя заготовка

```
1. @TBD
2. с 4 по 5
3. TBD
```

> Пункт 2 — формат «с текущего по целевой», как `с 1 по 2` в примере. Пункт 3 — ссылка на сообщение с одобренным отчётом, а не на канал.
