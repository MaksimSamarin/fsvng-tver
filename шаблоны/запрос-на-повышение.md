# Запрос на повышение

Подаётся в `#╏📘・запрос-на-повышения` **после** того, как на отчёте в `#🛡️отчет-на-повышение-курсанты` проставлена ✅.

## Форма (порядок пунктов менять нельзя)

```
1. @Ваш тэг
2. Статик
3. Текущий ранг - ранг на который повышаетесь
4. Ссылка на ваш одобренный отчет на повышение
5. @[👮] Кадровая служба ФСВНГ
```

## Эталонный пример из правил

```
1. @Нач.КС | Симон Матвиенков | 935
2. 935
3. 17-18
4. #🛡️отчет-на-повышение-курсанты
5. @[👮] Кадровая служба ФСВНГ
```

## Моя заготовка

```
1. TBD
2. TBD
3. 1-2
4. TBD
5. @[👮] Кадровая служба ФСВНГ
```

> Пункт 3 — формат «текущий-целевой», как `17-18` в примере. Для первого повышения это `1-2`.
