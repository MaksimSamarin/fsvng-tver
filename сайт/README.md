# Сайт «База знаний ФСВНГ»

Одностраничный сайт для курсантов: памятка, полные тексты уставов, лекции, система повышения и экзамен. Собирается скриптом из материалов базы — руками HTML не правится.

**Опубликован:** https://claude.ai/code/artifact/dd36cbb3-c577-43bf-82b6-44ace7772edf
**Файл для пересылки:** [dist/памятка-курсанта_файл.html](dist/памятка-курсанта_файл.html) — открывается двойным кликом, работает офлайн.

---

## Как пересобрать

```
cd сайт
python build.py
```

Собирает оба файла в `dist/` за пару секунд. Публикация — через Claude Code, тем же URL.

Если добавились или заменились фотографии:

```
python images.py     # сжимает фото и кодирует в исходники/photos.json
python build.py
```

## Структура

| Файл | Назначение |
|------|------------|
| `build.py` | Сборщик: собирает страницу из уставов, лекций и правил |
| `images.py` | Сжимает фото из `../Фото` и кодирует в base64 |
| `исходники/template.html` | Каркас: стили, вкладки, навигация, скрипты |
| `исходники/memo_src.html` | Памятка курсанта — 12 разделов |
| `исходники/exam_src.html` | 20 вопросов экзамена |
| `исходники/photos.json` | Все изображения в base64 (около 2 МБ) |
| `исходники/посты-вч/` | Фото постов воинской части из Google Docs |
| `dist/` | Готовые файлы, их и публикуем |

## Откуда берётся содержимое

| Вкладка | Источник |
|---------|----------|
| Памятка | `исходники/memo_src.html` |
| Устав ВС | `../правовая/источники/устав-вс-и-фсвнг_оригинал.txt` |
| Дисциплинарный | `../правовая/источники/дисциплинарный-устав_оригинал.txt` |
| Караульный | `../правовая/источники/устав-караульно-постовой-службы_оригинал.txt` |
| Лекции | `../docs/лекция-*.md`, `../docs/присяга.md` + фото постов и дресс-кода |
| Повышение | Свёрстано прямо в `build.py` — маршрут, задачи, каналы |
| Экзамен | `исходники/exam_src.html` |

> Уставы вставляются **дословно** из оригиналов. Правишь `.txt` — правится сайт.

## Что делает сборщик автоматически

- **Разбирает уставы** на главы и статьи, проставляет якоря и строит оглавление
- **Конвертирует Markdown** лекций в HTML: таблицы, списки, блоки команд с кнопкой «Копировать»
- **Вырезает служебное:** авторские шапки лекций, даты, ссылки на файлы базы, которых у курсантов нет
- **Делает ссылки кликабельными**, а упоминания каналов Discord превращает в ссылки-плашки
- **Короткие реплики** в диалогах (присяга) оформляет как реплики, а не как команды
- **Встраивает изображения** из `photos.json`

## Если обновился устав

1. Скачать свежий текст:
   ```
   curl -sL -o "../правовая/источники/<имя>_оригинал.txt" \
     "https://docs.google.com/document/d/<ID>/export?format=txt"
   ```
2. Сверить нумерацию статей со старой версией — она может сдвинуться
3. Поправить ссылки на статьи в конспектах и шпаргалке
4. `python build.py` и опубликовать

Ссылки на документы — в [ИСТОЧНИКИ.md](../ИСТОЧНИКИ.md).

## Что умеет страница

- **Семь вкладок**, слева — навигация по разделам текущей вкладки
- **Поиск** по оглавлению: вбил «оружие» или «6.1» — список сжался до совпадений
- **Отметки «Выучил»** по разделам памятки, прогресс сохраняется в браузере курсанта
- **Копирование** докладов и форм одной кнопкой
- **Экзамен**: вопрос раскрывается по клику, счётчик раскрытых
- Светлая и тёмная тема, работает на телефоне

---

## Ограничения

- Изображения зашиты в файл через base64 — внешние картинки на опубликованной странице блокируются
- Из-за этого страница весит около 2.2 МБ; при добавлении фото сжимать сильнее в `images.py`
- Отметки «Выучил» хранятся в браузере конкретного человека и не синхронизируются
