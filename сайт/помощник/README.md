# Помощник по документам

Курсант описывает ситуацию своими словами — помощник отвечает порядком действий и ссылками на статьи. Отвечает **только** по документам с сайта — уставы, Уголовный кодекс, КоАП, лекции, правила фракции: база знаний собирается из тех же источников, что и сама страница.

## Как устроено

```
сайт/помощник/
  kb.py          собирает базу знаний из правовая/источники/*.txt, правовая/законы/*.md и docs/*.md
  keys.json      разговорные формулировки к статьям — как курсант спросил бы; только для поиска
  kb.js          результат сборки — 432 фрагмента (статьи уставов и кодексов + разделы лекций)
  vec.py         считает векторы фрагментов через реле → kb-vec.js (запускать на сервере реле)
  vec_check.py   калибровка порогов: косинусы контрольных вопросов к статьям
  kb-vec.js      векторы 432 × 1024, int8, ~580 КБ; модель зафиксирована внутри
  worker.js      Cloudflare Worker: отбор нужных фрагментов + обращение к модели
  wrangler.toml  конфиг воркера
```

### Как ищутся статьи — три слоя

1. **Слова.** Основы слов, стоп-слова, IDF, совпадение начала слова, словарь сленга `SYN`. Заголовок статьи весит вдвое.
2. **Разговорные фразы** (`keys.json`, ~1100 штук к 181 фрагменту уставов, лекций и правил). Написаны вручную: «залипать в телефон на кпп» → УКПС ст. 36. Весят как заголовок. Модели не показываются — иначе она цитировала бы их как устав. Добавить фразу = добавить строку в JSON и пересобрать `kb.py`; на векторы это не влияет.
3. **Векторы.** Вопрос уходит на реле → `qwen/qwen3-embedding-4b` (OpenRouter, ~$0.02 за миллион токенов, тысяча вопросов — десятая доля цента), воркер считает косинусы к 432 статьям в памяти и сливает ранги со словесным поиском (RRF). Калибровка 18.09.2026: чужие вопросы дают к статьям 0.36–0.43, верные — 0.54–0.70; пороги `VEC_MIN`/`VEC_ACCEPT`/`VEC_STRONG` = 0.45/0.50/0.58. Не ответило за 4.5 с — ищем словами. Точные запросы (номер статьи, названный документ, «что такое статья») векторы не используют.

**Модель эмбеддингов менять нельзя без пересчёта `kb-vec.js`** — векторы статей и вопроса сравнимы только от одних весов. `check.py` сверяет подпись базы с подписью векторов и ругается, если базу пересобрали, а векторы нет.

Реле пишет **только текст вопросов** в `/var/lib/relay/questions.jsonl` — без адресов и ответов. Это единственная честная выборка для проверки поиска; тесты в `test.mjs` — лишь список уже пойманных провалов.

Модель работает внутри Cloudflare (Workers AI) — ключей и внешних сервисов не нужно вовсе.

**Почему не внешние провайдеры.** Groq отвечает `403` на запросы с адресов Cloudflare Workers, хотя тот же ключ с домашней машины даёт `200` — режет датацентр. OpenRouter гео-блокирует Россию: `403 Access denied by security policy` даже на главную без ключа. И через воркер это не обойти — проверено через `cdn-cgi/trace`: подзапрос воркера уходит с IP Cloudflare, но **страна посетителя передаётся дальше** (`loc=RU`). Курсант из РФ нажмёт кнопку — OpenRouter увидит Россию. Обход возможен только через реле вне Cloudflare (Deno Deploy, Vercel). Ключи обоих остались в секретах воркера неиспользованными.

Порядок работы запроса:

1. Страница шлёт `POST {"q": "текст ситуации"}` на адрес воркера.
2. Воркер отбирает **8 самых близких фрагментов** базы. Как считается близость:
   - слова приводятся к основе, служебные слова (`что`, `как`, `делать`, `кто`) отбрасываются;
   - редкое слово весит больше частого (IDF), совпадение в заголовке статьи — вдвое больше;
   - «напали» и «нападение» режутся в разные основы, поэтому совпадение первых четырёх букв тоже считается — с меньшим весом; но фрагмент без единого точного совпадения не считается найденным, иначе «кто выиграл чемпионат» цеплялся за слово «кто»;
   - словарь `SYN` переводит разговорное в канцелярское: «мат» → «оскорбление в неприличной форме», «угнал» → «неправомерное завладение»;
   - названный документ («что в УКПС про...») поднимает его статьи и гасит чужие с тем же номером;
   - вопрос «что грозит» поднимает кодексы, вопрос «что делать» — уставы, «что такое статья N» переключает модель на пересказ статьи;
   - процедурные главы КоАП (12–19) и общая часть УК (ст. 1–50) весят вдвое меньше — это порядок для полиции и суда, а не для постового; из-за них помощник однажды советовал «везти задержанного в отдел внутренних дел», хотя лекция и ВУ 5.3 велят передать Военной полиции;
   - номер в вопросе считается номером статьи только рядом со словом «статья» — иначе «3 ранг» цеплял ВУ ст. 3.1;
   - если лучший результат слабее порога, запрос к модели не уходит вовсе; если совпадение слабое — модели прямо говорят об этом, чтобы она отказала, а не сочиняла;
   - приветствия, «кто ты» и «спасибо» получают готовый ответ без обращения к модели.
3. Фрагменты уходят в модель `@cf/meta/llama-3.3-70b-instruct-fp8-fast` вместе с инструкцией отвечать только по ним. Если она занята — запасная `@cf/meta/llama-3.1-8b-instruct`.
4. Из строки «Основание:» вычищаются статьи, которых модели не давали, — она любит их выдумывать. Лекции и правила цитируются по названию документа. Из ответа вырезаются ссылки — модель переписывает адреса с ошибками — и случайные иероглифы, которые роняет fp8-модель.
5. Назад приходит `{"answer": "...", "refs": ["УКПС ст. 36", ...]}`.

Виджет хранит три последние пары вопрос-ответ и шлёт их вместе с вопросом, поэтому уточнения вроде «а после задержания что делать?» понимаются в контексте.

Если подходящих фрагментов не нашлось — запрос к модели вообще не уходит, курсант получает «в документах этого нет».

## Развернуть

Нужен только бесплатный аккаунт Cloudflare.

```
cd сайт/помощник
npx wrangler login
npx wrangler deploy
```

Привязка `[ai]` в `wrangler.toml` подключает модель — при деплое wrangler печатает строку `env.AI`.

Деплой напечатает адрес вида `https://fsvng-assistant.<поддомен>.workers.dev`.

## Включить на сайте

Адрес воркера кладётся в отдельный файл, HTML руками не правится:

```
echo https://fsvng-assistant.<поддомен>.workers.dev > сайт/исходники/ai_url.txt
python сайт/build.py
python сайт/check.py
```

Пока файла нет или он пуст — кнопка помощника на странице **не показывается**, всё остальное работает как раньше.

## Проверить, не сломался ли отбор

```
node сайт/помощник/test.mjs
```

Гоняет отбор на контрольных вопросах: находится ли КоАП ст. 5.4 по слову «мат», не перебивает ли УК ст. 37 караульную ст. 37, отсеивается ли «как приготовить борщ», чистятся ли выдуманные ссылки. Тест дёргает те же функции, что и боевой воркер, — не копию. Каждый вопрос, на котором помощник провалился у живого курсанта, добавляется туда как обязательный.

Полный прогон с живыми ответами модели — 28 вопросов по всем блокам, включая диалог с уточнениями и мусор, — делался 18.09.2026; ответы сверялись с оригиналами статей. Стоит повторять после правки промпта или базы.

## Обновить базу знаний

После правки уставов или лекций:

```
python сайт/помощник/kb.py
cd сайт/помощник && npx wrangler deploy
```

## Локальная проверка

```
cd сайт/помощник
npx wrangler dev --remote
```

Флаг `--remote` обязателен: модель живёт в облаке Cloudflare, локальной заглушки у неё нет. Поднимется на `http://localhost:8787`. Чтобы потыкать виджет, временно впиши этот адрес в `сайт/исходники/ai_url.txt` и пересобери — в `worker.js` разрешены `localhost` и открытие страницы файлом.

## Ограничения

- Разрешённые источники запросов перечислены в `ALLOW` в `worker.js` — при смене адреса сайта список нужно поправить.
- Бесплатный лимит Workers AI — 10 000 нейронов в сутки, сброс в полночь UTC (03:00 МСК). Проверено 18.09.2026: лимит кончился примерно на 85-м запросе, то есть **около 80 вопросов в день** на всю фракцию. После этого воркер отвечает «Дневной лимит помощника исчерпан», всё остальное на сайте работает. Расход виден в дашборде Cloudflare → AI → Workers AI. Упрёмся всерьёз — Workers Paid ($5/мес) или переключить `MODEL` на `@cf/meta/llama-3.1-8b-instruct-fp8`, она дешевле в разы.
- Каталог моделей меняется: `@cf/meta/llama-3.1-8b-instruct` сняли 30.05.2026, и запасная модель молча перестала работать. Актуальный список — `npx wrangler ai models list`. В каталоге есть `@cf/qwen/qwen3.8-27b`, `@cf/deepseek-ai/deepseek-v4-flash-0731`, `@cf/openai/gpt-oss-120b` — кандидаты на замену основной, если захочется сравнить.
- Ответ занимает 4–6 секунд, изредка до 12 при холодном старте.
- Модель может ошибиться в формулировке. На странице под формой стоит предупреждение, что это подсказка, а не приказ.
