# Требования к доказательствам

## Допустимые хостинги

Фото/видео фиксация принимается только с:

| Тип | Сервисы |
|-----|---------|
| Видео | YouTube, Rutube |
| Облако | Google Drive, Yandex Disk |
| Картинки | imgur, Yapx, Prnt, ibb |

> Фиксация должна иметь **исчерпывающие доказательства**, подтверждающие то или иное деяние.

Правила приёма скриншотов — канал «Требования к скриншотам для отчётов».

---

## Чек-лист перед загрузкой каждого скриншота

- [ ] Полный экран, без обрезки и редактирования
- [ ] Видна **плашка бодикамеры с красным индикатором** — камера включена везде, кроме построения на плацу
- [ ] Виден игровой ник по форме `Армия| Имя Фамилия | Статик`
- [ ] Виден таймер/время, если действие привязано ко времени (караул)
- [ ] Доклад написан в `/f`, а не в `/fb`
- [ ] Ссылка открывается без авторизации (доступ по ссылке для Google/Yandex Disk)
