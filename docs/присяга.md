# Принятие присяги

**Когда:** ежедневно **12:00 и 20:00 на плацу**, а также в любое время по договорённости.
О начале построения на присягу старший офицер докладывает **в новости**.

Требование для повышения **ранг 2 → 3**. По **ст. 1.11 Устава ВС** присяга обязательна для каждого прибывшего в часть; отказ или грубое нарушение — основание для увольнения.

> **Присяга для ФСВНГ проводится отдельно от ВС РФ — будьте внимательны.**


## Как проходит присяга

Инструктор собирает построение на плацу. Из строя поочерёдно вызывается **один человек**.

**Форма одежды:** принимающий — «Парадный китель с брюками», дающий присягу — «Парадный мундир с брюками». Выбирается в меню **F2 → Комплекты одежды → Фракционные**. OATH-UNIFORM-GALLERY

### Вызов из строя

**Инструктор:**
```
Курсант (Фамилия)
```
**Курсант:**
```
Я
```
**Инструктор:**
```
Для принятия торжественной присяги ко мне!
```
**Курсант:**
```
Есть
```
Курсант выходит из строя, подходит к офицеру **по кратчайшей траектории** и с последним шагом **выполняет воинское приветствие** — отдаёт честь. Только после этого докладывает:
```
Товарищ Старший сержант, курсант (Фамилия) для принятия военной присяги прибыл!
```
> **Честь отдать обязательно.** Доклад без воинского приветствия — нарушение порядка доклада и обращения к старшему, ст. 8 ДУ.

### Передача текста

**Инструктор:**
```
/me протянул папку с текстом присяги в руки новобранцу
```
**Курсант:**
```
/me взял папку с текстом присяги в руки
```

### Принятие

**Инструктор:**
```
Военную присягу принять!
```
**Курсант:**
```
Есть
```
Курсант **поворачивается лицом к строю** и произносит текст присяги — уже держа папку в руках:
```
Я, (Фамилия Имя), торжественно присягаю на верность своему Отечеству — Российской Федерации. Клянусь свято соблюдать Конституцию Российской Федерации, строго выполнять требования воинских уставов, приказы командиров и начальников. Клянусь достойно исполнять воинский долг, мужественно защищать свободу, независимость и конституционный строй России, народ и Отечество.
```
**Курсант** докладывает о принятии:
```
Товарищ Старший сержант, курсант (Фамилия) военную присягу принял!
```

### Завершение

**Инструктор:**
```
/do Присяга успешно принята новобранцем — Имя Фамилия.
```
```
Поздравляю с принятием присяги, встать в строй
```
**Курсант:**
```
Есть
```

Курсант возвращается в строй, вызывается следующий.

## На что смотрят при проверке отчёта

- Присяга **отыгрывается**, не пишется текстом. Письменная форма — только по веской причине, **заранее** согласованной с руководством.
- Перед тем как встать в строй — **снять бронежилет и убрать оружие из-за спины**.
- На плацу нельзя: телефон, разговоры, приём пищи, курение, неформальный вид — **ст. 21 ДУ**. Курение — ещё и ст. 12.1.
- Имя и фамилия в полной форме: Алексей, а не Лёха.
