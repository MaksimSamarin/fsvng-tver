# Система повышения курсантов ФСВНГ

Путь от 1 ранга до военного билета. Актуальная редакция на 21.09.2026 — по посту Нач.АВНГ от 20.09.2026.

## Ранг 1 → 2

Шесть требований. Выезд за территорию ВЧ — только в сопровождении сотрудников Академии ВНГ, самостоятельный выезд запрещён.

| # | Требование | Что нужно сделать |
|---|------------|-------------------|
| 1 | Удостоверение | Получить в здании правительства |
| 2 | Лекция по внутренним НПА | Прослушать. Инструктор проводит её **разово, сразу по всем шести документам** |
| 3 | Лекция-экскурсия по ВЧ | Прослушать |
| 4 | Государственная спец. связь | Присоединиться и получить роль, инструкция ниже |
| 5 | Занятие по физподготовке | **2 скриншота:** начало и конец тренировки |
| 6 | Принятие присяги | **1 скриншот.** Отыгровка по процедуре, ежедневно в 12:00 и 20:00 на плацу |

### Шесть документов лекции по НПА

1. Лекция «Постовая служба»
2. Лекция по субординации
3. Лекция «Строевая подготовка»
4. Дресс-код ФСВНГ
5. Дисциплинарный устав
6. Устав ВС РФ и ФСВНГ

Экзамен на этом этапе не сдаётся — он перенесён на этап 2 → 3 и сдаётся **один раз по всему материалу целиком**, а не по каждому блоку.

## Подключение к спец. связи

Четыре шага. Результат — скриншот профиля с ролью **Тверской** и ником по форме.

1. Присоединиться к спец. связи «Государственные фракции РО»: https://discord.gg/5kTutqS8K
2. Нажать **«Получить роль»**. Получение роли гос. служащего пока недоступно — получаете **только Тверской**: https://discord.com/channels/1538879177917210668/1538884293592354900/1543186737965309994
3. После этого появится сообщение о получении роли
4. Отредактировать свой ник по форме: `Армия | Имя Фамилия | Статик`

### Что идёт в отчёт

- Скриншот профиля с ролью **Тверской**
- Ник строго по форме `Армия | Имя Фамилия | Статик`

## Ранг 2 → 3

Пять требований. Выезд с территории ВЧ — только с сотрудниками Академии ВНГ, самостоятельный выезд запрещён.

| # | Требование | Доказательства |
|---|------------|----------------|
| 1 | Стрельбище | **2 скриншота:** начало и завершение занятия |
| 2 | Тренировочная площадка | **2 скриншота:** начало и конец полосы препятствий |
| 3 | Караул на КПП №1 или КПП №2 Алабино — **1 час** | **5 скриншотов** каждые 15 минут с докладом в `/f` |
| 4 | Экзамен по внутренним НПА ФСВНГ | **1 скриншот результата.** Один экзамен сразу по всем шести документам |
| 5 | Строевая подготовка | **2 скриншота:** начало и конец занятия. Отдельное занятие с инструктором, не путать с лекцией на этапе 1 → 2 |

### Тайминг караула

Заступили в 16:00 → скриншоты в **16:00, 16:15, 16:30, 16:45, 17:00**. Первый — заступление на пост, последний — сдача поста.

## После 3 ранга

После присвоения 3 ранга курсант **автоматически зачисляется в РВО** — Роту вневедомственной охраны. Выбирать подразделение не нужно.

Находясь в РВО, можно подать заявку на перевод в другое подразделение. Перевод — только по одобрению принимающего подразделения.

| Подразделение | Чем занимается |
|---|---|
| **РВО** | Рота вневедомственной охраны — сюда зачисляют после 3 ранга |
| **ОМОН** | Отряд мобильный особого назначения |
| **ОСБ** | Отдел собственной безопасности — нарушения внутри ФСВНГ |
| **КС** | Кадровая служба — кадровая работа по всему ФСВНГ |
| **АВНГ** | Академия ВНГ — обучение курсантов |

Кадровая служба и АВНГ — **два разных подразделения**.

Дальше военнослужащий растёт по системе повышения **своей структуры**.

## Порядок подачи

**Шаг 1. Отчёт на повышение** — сообщением в канал отчётов, по форме ниже, с доказательствами по каждой задаче этапа. Ждать отметки ✅.

**Шаг 2. Запрос на повышение** — только после одобрения отчёта, в канал запроса, со ссылкой на одобренный отчёт.

### Форма отчёта

Четыре пункта, порядок не менять. Отчёт проверяет Академия ВНГ — последней строкой её тег.

```
1. Тегаете себя через @
2. С какого на какой ранг повышаетесь
3. Доказательства
4. Тегаете @[🎓] Академия Войск Национальной Гвардии
```

### Пример отчёта

Ранг 1 → 2. В третьем пункте — по одной строке со ссылкой на доказательство на каждую задачу этапа; для 2 → 3 это стрельбище, тренировочная площадка, караул, экзамен и строевая подготовка.

```
1. @Нач.АВНГ | А.Власов | 89014
2. 1-2
3.
1) удостоверение - [ссылка]
2) Лекция по внутренним НПА - [ссылка]
3) Лекция-экскурсия по ВЧ - [ссылка]
4) Тренировка по физ.подготовке - [ссылка]
5) Получение роли на сервере гос.структур - [ссылка]
4. @[🎓] Академия Войск Национальной Гвардии
```

### Форма запроса

Четыре строки, порядок не менять.

```
1. Тег себя (через @)
2. Текущий ранг - ранг на который повышаетесь
3. Ссылка на ОДОБРЕННЫЙ ОТЧЁТ
4. @Тег Кадровой службы
```

### Пример запроса

```
1. @Зам.КС | Денис Спасский | 65597
2. с 1 по 2
3. [ссылка на одобренный отчёт в #отчет-на-повышение-курсанты]
4. @[👮] Кадровая служба ФСВНГ
```

**Заявка не по форме не рассматривается.** Первой строкой — свой тег через @, последней — тег Кадровой службы `@[👮] Кадровая служба ФСВНГ`. Ссылка в третьей строке — на уже одобренный отчёт.
